# zw-skills

A catalog of personal agent skills installed on this Mac, with usage examples, installation guidance, source links, dependencies, and bundled workflows.

**Snapshot:** 2026-10-19T20:28:26-04:00 (America/New_York).

This catalog covers **personal skills only**. Built-in skills, plugin-provided skills, broken installations, and unfinished templates are excluded. The snapshot was filtered without rescanning or changing any installed skills.

This repository contains documentation and inventory metadata only. It does not contain skill packages, an installer, credentials, or private configuration files.

## At a glance

- **37 personal skill packages**, including the shared support package `nature-shared`.
- Usage, source evidence, installation guidance, dependencies, and subskills are preserved in each detailed entry.

Read the detailed entry before installing: some local/custom skills have no recovered public source. For those, restoring the original package is necessary; cloning this catalog alone cannot reinstall them.

## Choose and install

1. Find a skill in the categories below and open its detailed entry.
2. Check its dependencies, source confidence, and installation method.
3. For a verified public skill, follow its installer prompt. For a custom skill with unknown provenance, transfer its complete original package.
4. Preserve sibling support packages such as `nature-shared` when restoring Nature skills.

See the [official skill documentation](https://learn.chatgpt.com/docs/build-skills) for the general skill format.

## Findings and limitations

- `nature-shared` is a support package used by other Nature skills, not a standalone user workflow.
- `grill-me` delegates to `grilling` and requires explicit invocation.
- `nature-proposal-writer` exposes the `researchwrite` invocation name.
- ARS includes five workflow modules and sixteen command aliases. In Codex these aliases go through the ARS router rather than native slash-command registration.
- Public sources were found for the Nature collection, NIW suite, Junshi, grilling, document conversion, PDF, and Playwright. Nature’s recorded receipt commit is publicly accessible. PDF and Playwright manifests exactly match the local vendor checkout; other provenance confidence is stated per entry. ARS upstream sources are known, but its installed Codex adapter has no recovered distribution source.
- Current public sources may differ from the recorded installed versions. Only manifest fingerprints are recorded; whole package integrity and runtime dependencies were not tested.
